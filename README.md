## About application
  The application is created for the purpose of managing major assignments for students. Allows lecturers to track and manage coursework.
## Features
  + Managing major assignments for students
  + Check work progress
## Technology
  + Netbeans
  + Java
  + JavaSwing
## Install and run
  + Clone project
  + Download Netbeans and JDK (8.0 or more)
  + Run project with Netbeans
